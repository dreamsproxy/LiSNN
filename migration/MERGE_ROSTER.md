# LiSNN consolidation roster

## Included

- LiNN: complete pinned donor snapshot.
- BioEmulator: complete pinned donor snapshot, including EMNET and historical SNN variants.
- VolumetricSNN: complete pinned donor snapshot for spatial and volumetric experiments.
- Existing LiSNN timecode, hypothesis-substrate, planning-graph, and variant code already resident in the destination repository.

## Excluded

- D-LiNN: deliberately removed from the merge roster.
- Python-Statistical-Evolution-Simulator-PySES: unrelated to LiSNN.
- MycoNet: empty repository at consolidation time.
- Other dreamsproxy repositories: no established LiSNN architectural role in the approved roster.

## Integration rule

A repository being included in the consolidation does not make its code active. Donor behavior enters LiSNN only through a reviewed adapter, compatibility layer, or clean rewrite with tests.
